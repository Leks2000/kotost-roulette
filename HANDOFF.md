# kotost_roulette — HANDOFF (0.1, 11.11.2026)

## Где что
- `roulette.rs` — весь мод (модуль `crate::game::kotost_roulette`): таблица цен, сервер (бросок, ставка,
  награда), экран, колесо, поиск. Внизу — таблица по умолчанию (~417 предметов, русские названия).
- `hooks/*.rs` — однострочные хуки; `horizon-mixin.toml` — 11 HEAD-инъекций через `hook = ...`.
- Конфиг: `config/kotost_roulette.txt` в папке игры сервера (одиночная — папка игры). Пишется сам, если нет;
  перечитывается при изменении. Клиент получает таблицу от сервера.
- Сеть: сервер → клиент `kotost_roulette:table` (части таблицы), `:open` (открыть экран), `:result`;
  клиент → сервер `kotost_roulette:spin` (слот, сколько, id ставки, id и число награды).

## Решения
- UI: **свой экран мода** (`native_mod_screen_open`) — дешевле отдельного меню: рисуем в `screen_render_post`,
  клики/колесо/клавиши через screen-хуки. Инвентарь рисуется внизу экрана, клик по слоту = ставка.
- Предмет «Рулетка» = `minecraft:clock` с именем «Рулетка» (без контент-мода и текстур). ПКМ → `use_item` на
  сервере → открыть экран. Также `/roulette`.
- x2…x10: награда — предмет таблицы, чьи очки ближе всего к ставке × N (в пределах 2 % — самый дорогой, т. е.
  меньше штук). Свой выбор: клик по слоту награды → поиск. Колесо мыши над слотами — количество (Shift ×10).
- Бросок только на сервере: ставка снимается `native_set_inventory_slot` (с проверкой, что стак тот же) в момент
  броска; награда — через 3,1 с (`native_give_stack`, остаток — `minecraft:item` под ноги; игрок вышел — в его
  файл, иначе ждёт возвращения). Только «чистые» стаки (без чар, имён, износа).
